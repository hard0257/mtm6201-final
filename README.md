# The Green Fork – Final Website (MTM6201 Final Project)

## About This Project
This project is a responsive website created as my final assignment for MTM6201 (Web Development). The website is based on my Figma wireframes and mockups from my User Experience Design course. The website represents a plant-based restaurant called **The Green Fork**.

The website contains three main pages:
- Home
- Menu
- About

---

## My Development Process

I started this project by designing wireframes and layouts in Figma. I planned the structure of each page before writing any code. After that, I created the HTML structure and added Bootstrap to help with responsiveness and layout.

Once the main structure was complete, I customized the design using my own CSS file. I used CSS variables to control the color theme and make sure everything was consistent with my Figma designs.

I tested the website regularly on desktop, tablet, and mobile screen sizes to make sure it worked properly on all devices.

---

## Challenges I Faced

The biggest challenge was making the website match my Figma design exactly. Spacing, alignment, and responsiveness were difficult at first.

I solved these problems by:
- Using the Bootstrap grid system
- Using Flexbox for better alignment
- Testing frequently and adjusting margins and padding
- Using media queries for mobile and tablet layouts

Another challenge was making the website accessible. I added alt text to images, made sure text was readable, and designed the site so it can be used with a keyboard.

---

## What I Learned From This Project

From this project, I learned:
- How to properly use Bootstrap for responsive layouts
- How to use CSS variables for theme customization
- How to make websites work on mobile, tablet, and desktop
- How to use the `<picture>` tag and `srcset` for responsive images
- How to improve accessibility in web design

This project helped me understand real-world web development much better.
